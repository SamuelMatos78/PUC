# PUC Minas — Engenharia de Software

Este repositório é destinado ao armazenamento das atividades acadêmicas realizadas durante o curso de **Engenharia de Software da PUC Minas** que possuem como requisito de entrega a disponibilização do projeto por meio do **GitHub**.

O repositório reúne trabalhos, exercícios e projetos desenvolvidos ao longo das disciplinas, mantendo cada atividade organizada em seu respectivo diretório.

## Organização

Os conteúdos são organizados por disciplina e, dentro delas, por atividade ou projeto.

Exemplo:

    PUC/
    ├── aplicacoes_web/
    │   ├── Atividade_1/
    │   ├── Atividade_2/
    │   └── ...
    └── outras_disciplinas/
        └── ...

## Objetivo

Centralizar em um único repositório as entregas acadêmicas que necessitam especificamente do GitHub, facilitando o versionamento, a organização e o acesso aos projetos desenvolvidos durante o curso.

> Este repositório possui finalidade acadêmica.
